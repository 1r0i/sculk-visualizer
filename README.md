# Sculk Visualizer

A client-side Fabric mod that shows a sculk sensor's detection range, signal strength, and how wool blocks vibrations.

Right-click a sensor with an empty hand to toggle its display. Requires Fabric Loader and Fabric API.

## Commands

- `/sculkvisualizer clear`: turn off all displays
- `/sculkvisualizer numbers`: toggle signal strength numbers (off by default)
- `/sculkvisualizer seethrough`: toggle see-through mode

The same actions can be bound to keys under *Options > Controls > Key Binds* (unbound by default).
